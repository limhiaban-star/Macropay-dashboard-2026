# Macropay 2026 - Dashboard de Ventas e Inventario para Proveedores

Dashboard web interactivo para la visualización de indicadores clave de rendimiento (KPIs) de Ventas e Inventarios Macropay 2026.

## 🚀 Características
- **Autenticación por Proveedor**: Sesión individual para marcas (BAJAJ, BODESA, DINAMO, MOTO ROAD, VELOCI) y vista global para administradores.
- **Reporte de Ventas**: Ranking de modelos, top estados, tipo de sucursal, cuotas de mercado y tabla de crecimiento MoM con proyección de ventas con fórmula condicional IF.
- **Reporte de Inventario**: Desglose por Libre Utilización, Inspección de Calidad e Inventario Bloqueado, con semáforo de alerta en rojo cuando el bloqueo supera el 5.0%.
- **Exportación Excel**: Botón de descarga `.xlsx` para todas las tablas dinámicas.
- **Identidad Corporativa**: Paleta oficial Pantone 2728C (`#1F49B6`) y Yellow C (`#F6DC00`).

## 🛠️ Instalación y Uso Local
```bash
npm install
npm start
```
El dashboard se abrirá en `http://localhost:3000`.
